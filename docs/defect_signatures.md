# 웨이퍼 맵 결함 시그니처와 장비 원인 — 장비사 기술지원 시점

웨이퍼 맵의 불량 분포는 공정 어딘가의 비대칭을 그대로 찍어낸 것이다. 반경 방향으로 대칭이면 회전 대칭인 장비 요소(척, 샤워헤드, 스핀 척, 플라즈마)를, 방위각 한쪽에 치우치면 비대칭 요소(로봇 핸드오프, 배기구, 가스 주입 위치)를, 선이면 기계적 접촉을 먼저 의심한다. 이 문서는 분류기가 내는 8종 패턴마다 "왜 그 모양이 나오는가", "어느 TEL 장비군의 어떤 증거를 꺼내는가", "어디까지가 우리 장비 원인이고 어디부터 타사 장비 인계인가"를 적는다.

이 문서는 **장비사(TEL) 기술지원 엔지니어 시점**으로 쓴다. 고객(수율 엔지니어)이 빈 맵·로트 이력·재테스트 결과를 소유하고, 장비사 엔지니어는 고객이 에스컬레이션할 때 비로소 맵을 본다. 그가 소유하는 것은 장비 쪽 증거 — 장비 알람/이벤트 로그, 부품 누적 카운터(RF 시간·웨이퍼 매수), 레시피 변경 이력, PM·부품 교체 기록, 로봇 티칭/센터링 로그, 챔버 시즈닝 이력, ESC He 압력·존 온도 로그 — 다. 그래서 각 패턴 표는 '고객 측 증거'와 '장비 측 증거'를 나누고, 마지막에 'TEL 원인 vs 타사 인계' 판정 기준을 적는다. 조치 문구의 단일 소스는 `wafer_pattern_classifier.ACTION_DETAIL`이며 `tests/test_actions.py`가 코드와 이 문서의 키 일치를 검사한다.

주의할 점이 셋 있다.

- **WM-811K는 다이 단위 pass/fail 맵(사실상 웨이퍼 테스트 빈 맵)이라 모든 공정 단계의 결과가 누적된 것이다** [43]. 따라서 아래 표는 확정이 아니라 **의심 순서**다. 같은 모양이라도 로트 전체에 나오면 공정 조건, 한 장에만 나오면 핸들링이나 파티클 이벤트일 가능성이 높다. 원인 특정은 맵 하나가 아니라 로트 이력, 장비 측 로그, 공통성 분석에서 끝난다.
- **결함 부분집합은 로트당 평균 3.2장이다**(25,519장 / 8,047로트, 저장소 계산 [40]). 원본 WM-811K의 로트는 25장 묶음이지만 [44] 라벨이 있는 결함 웨이퍼만 보면 로트당 1~2장인 로트가 다수일 가능성이 높다. 그래서 아래 '로트 안에서 반복되는가', '노치 기준 방위각이 같은가', '슬롯에 몰리는가' 같은 로트 내 분석은 **WM-811K 실측에서는 대부분의 로트에서 n이 부족**하다. 해당 스크립트(`wm811k_azimuth.py`, `wm811k_scratch_shape.py`, `wm811k_slot.py`)는 n 미만이면 'insufficient'를 내고, 로직은 합성 데이터로만 확인한 것이다.
- 장비 서술은 공개 자료(제품 페이지·특허·논문·교과서 수준의 공정 물리) 기준이다. TEL 내부 구현, 매뉴얼의 PM 주기, 소모품 교체 기준은 모른다. '(추정)' 표시는 확인되지 않은 것이다. 각주 `[n]`은 [`references.md`](references.md)의 번호다.

### '분류기 특징' 행의 수치 읽는 법

- **AUC** — README '진단 과정'에 적힌 특징별 일대다 AUC(실측, 단일 실행 값).
- **F1(5회)** — 로트 분할 5회 평균(20개 특징 RF, README 결과표).
- **F1(단일)** — 시드 42 단일 분할 값. 5회 평균과 섞지 않는다.
- **(가설, 실측 미측정)** — `wm811k_improve.ROBUST_FEATURES`(`isolated_frac`, `n_comp_sig`, `sig_frac`, `fail_nb_mean`, `big_extent`, `big_len`, `big_edge_touch`, `second_frac`). 합성 데이터로 파이프라인이 끝까지 도는 것만 확인했고 실측 AUC·F1은 없다. 합성에서의 결과는 로직 확인이지 성능이 아니다.

## 패턴별 정리

### EDGE_RING — 외곽 전둘레 (edge ring)

| 항목 | 내용 |
|---|---|
| 모양 | 웨이퍼 가장자리를 따라 띠 모양으로 불량. 방위각 전체에 고르게 분포 |
| 메커니즘 | 웨이퍼 가장자리는 모든 회전 대칭 공정에서 경계 조건이 바뀌는 곳이다. 플라즈마 식각에서는 시스(sheath)가 웨이퍼 끝에서 휘어 이온 입사각과 식각률이 달라지고, 이를 보정하는 부품이 엣지 링(포커스 링)이다. 엣지 링은 소모품이라 마모되면 시스가 왜곡되어 엣지 식각률이 변하고 이온 틸트(피처 기울어짐)가 생긴다. 최근 장비는 링 높이 보정과 엣지 DC 바이어스로 보정하며, **보정 손잡이가 한계에 닿은 시점이 교체 시점**이다. 교체 시점은 누적 RF 시간·전력 카운터로 판단한다 [15][17]. ESC는 엣지 실 밴드가 마모되거나 폴리머로 오염되어 He가 새면 바깥 존 냉각이 약해져 가장자리 온도가 뜬다 [18]. CVD에서는 히터 가장자리 온도 강하와 가스 체류 시간 차이로 막 두께가 달라진다. 코터는 EBR(엣지 비드 제거) 폭 설정이 레이어별로 불일치하면(한 레이어만 넓으면) 가장자리 다이가 통째로 죽는다 [21][22]. 배치 세정(웻벤치)은 배스 유동으로 가장자리 집중 결함을 만든다 [33]. CMP는 리테이닝 링 마모·평탄도 불량으로 패드 반발이 바뀌어 가장자리 제거율이 중심과 달라진다(과연마든 저연마든 엣지 프로파일 이탈이지 '과연마' 단정이 아니다) [27] |
| 원 논문 귀속 | ring → 식각 [38] |
| 기본 심각도 | 로트 홀드 검토(`lot_hold`). 로트 안에서 반복되면 한 단계 올린다 |
| TEL 장비(모듈) | Tactras / Episode UL 식각: 엣지 링(포커스 링) RF 카운터·높이 보정·엣지 DC 바이어스, ESC 엣지 존 온도·He 압력·실 밴드. Triase+ / Episode / NT333 성막: 히터 엣지 존, 센터/엣지 가스 분배비. TELINDY PLUS 퍼니스: 보트 슬롯 위치(상/중/하)별 패턴 비율 변화, 석영 보트·튜브 상태 [32]. CLEAN TRACK LITHIUS Pro 코터: EBR 폭 레이어별 설정. EXPEDIUS 배치 세정: 배스·건조 단계 엣지 집중 [1] |
| 타사 장비(인계) | CMP 리테이닝 링 마모(타사): 엣지 제거율이 중심과 달라짐(과연마·저연마 모두 가능) [2][27] |
| 고객 측 증거 | 빈 맵의 링 폭·반경 추세(로트별). 로트 이력: 어느 식각/성막/코터/세정 챔버를 거쳤는가, CMP 직후인가. 인라인 두께·CD 맵(파라메트릭 맵)의 엣지 프로파일 |
| 장비 측 증거(TEL 엔지니어가 꺼내는 것) | 엣지 링 누적 RF 시간·전력 카운터와 교체 이력. 링 높이 보정·엣지 DC 바이어스 보정값 이력. ESC 존별 온도·He 압력 로그, 실 밴드 교체 기록. 레시피 변경 이력, PM·챔버 시즈닝 이력. 히터 존 온도 로그(성막), EBR 폭 설정값(코터) |
| 점검 순서 | (1) 링 폭 추세: 로트 사이에 서서히 넓어지면 소모품 마모, 갑자기 생기면 부품 교체·레시피 변경·PM 시점과 대조 (2) 식각: 엣지 링 RF 카운터와 보정값이 한계에 닿았는지 (3) ESC 엣지 존 온도·He 압력 로그, 실 밴드 상태 (4) 성막: 히터 엣지 존, 가스 분배비. 퍼니스는 슬롯 위치별 비율(`wm811k_slot.py`) (5) 코터: EBR 폭 레이어별 설정 대조 (6) 배치 세정 엣지 집중 / CMP는 인계 |
| TEL 원인 vs 타사 인계 | 링 폭 변화 시점이 TEL 챔버의 RF 카운터·보정값 한계·PM 시점과 겹치면 TEL 원인. 로트 이력에서 CMP 직후 로트에만 생기면 타사 인계 |
| 분류기 특징 | `r_mean` AUC 0.956, `outer_cover`(외곽 각도 커버리지) AUC 0.808. F1(5회) 0.98. EDGE_LOC과는 커버리지로 갈린다 |

### EDGE_LOC — 외곽 국소 (edge local)

| 항목 | 내용 |
|---|---|
| 모양 | 가장자리 한쪽 구간(호)에만 불량 |
| 메커니즘 | 회전 대칭이 깨진 것이므로 방위각 의존 요소를 본다. 반송 로봇이 웨이퍼를 척 중심에서 어긋나게 놓으면 한쪽 가장자리가 엣지 링에 가깝거나 멀어진다. 배기 포트 방향의 유동 비대칭, 가스 주입구 위치도 같은 모양을 만든다. 코터 EBR이 웨이퍼 중심에서 편심되면(노즐 위치·척 센터링) 한쪽은 과도 제거(다이 손실), 반대쪽은 미제거(막 팝핑·박리)로 호 모양이 난다 [23]. 가장자리 한 점의 치핑(깨짐)이면 그 주변이 호 모양으로 죽는다. **노치 정렬 오류**는 그 자체가 엣지 불량 원인이 아니라, 기존 비대칭이 노치 기준으로 회전해 보이는 원인이다 — 같은 패턴이 웨이퍼마다 다른 각도에 나타난다. **리프트 핀**은 같은 반경에 3개(120°)라 단일 호의 원인으로는 부적절하며, 핀 서명은 LOC 행의 '같은 반경 3점'이다 [31] |
| 원 논문 귀속 | (없음) |
| 기본 심각도 | 로트 홀드 검토(`lot_hold`) |
| TEL 장비(모듈) | 모든 TEL 장비 공통: EFEM 반송 로봇 센터링·티칭, 얼라이너. Tactras / Episode UL 식각, Triase+ / Episode 성막: 배기·가스 주입 비대칭. CLEAN TRACK LITHIUS Pro: EBR 편심(노즐 위치·척 센터링) [1][23] |
| 타사 장비(인계) | 타사 장비의 반송계: TEL 챔버를 거치지 않은 로트에도 같은 각도면 그쪽 인계 |
| 고객 측 증거 | 빈 맵에서 호의 방위각(노치 기준)과 폭, 로트 내 재현 여부. 로트 이력(챔버 ID·스테이션). 웨이퍼 엣지 검사 결과(치핑) |
| 장비 측 증거(TEL 엔지니어가 꺼내는 것) | 반송 로봇 센터링 오프셋·티칭 로그. 얼라이너 노치 검출 로그. 챔버 배기·가스 주입 위치(도면)와 비교할 방위각. EBR 노즐 위치·척 센터링 설정, EBR 폭 4방향 측정값(코터). 레시피·PM 이력 |
| 점검 순서 | (1) 불량 호의 방위각을 노치 기준으로 재서(`wm811k_azimuth.py`) 같은 챔버를 거친 웨이퍼끼리 비교: 같은 각도면 챔버 고정 요소(배기구·가스 주입 위치), 제각각이면 핸들링 (2) 로봇 센터링 오프셋·티칭 로그, 얼라이너 노치 정렬 로그 (3) 코터 EBR 편심 — EBR 폭 4방향 측정 (4) 챔버 비대칭 요소를 도면과 대조 (5) 엣지 치핑 — 엣지 검사, 엔드이펙터·FOUP 슬롯 접촉 흔적 |
| TEL 원인 vs 타사 인계 | 노치 기준 각도가 TEL 챔버 도면의 비대칭 요소나 로봇 오프셋 로그와 맞으면 TEL 원인. TEL 장비를 안 거친 로트에서도 같은 각도가 재현되면 타사 인계. 단, WM-811K는 배열 방향과 물리 노치의 대응이 문서화되어 있지 않아 [46] 절대 각도가 아니라 **로트 안 상대 각도**로만 해석한다(`--notch-deg`로 가정을 명시) |
| 분류기 특징 | `r_mean` 높고 `dir_c`(방향 집중도) 높음. F1(5회) 0.91. LOC과의 구분은 `big_r`·`big_r_min`(AUC 0.846 / 0.807)이 효과, 각도 폭 `big_span`은 AUC 0.520으로 무용(두 클래스의 각도 폭이 54° vs 52°로 같았다). `big_edge_touch`(최대 성분이 가장자리에 닿은 비율)는 (가설, 실측 미측정) |

### CENTER — 중심부 (center)

| 항목 | 내용 |
|---|---|
| 모양 | 중심 원반 영역에 불량 |
| 메커니즘 | 가장자리의 반대로, 회전 대칭 공정의 중심 조건이다. ESC의 중심 존 온도·히터, 존별 He 압력 설정(중심/엣지 압력비)이 중심 온도를 바꾼다. He 누설은 엣지 실 밴드와 리프트 핀 홀에서 나므로 **'중심 누설'은 보지 않는다**(핀 홀 누설이면 같은 반경 3점으로 나타난다) [18]. VHF CCP 식각에서는 전극 지름이 유효 RF 파장의 절반 수준이 되면 **정재파 효과로 중심 전력이 높아진다(center-high)** — 정합기 출력단 설정이나 저주파 병용이 조절 손잡이다 [19]. 샤워헤드 중심 홀 막힘, 스핀 코팅의 중심 두께(도포 노즐 센터링과 분사 타이밍), 단일 웨이퍼 세정에서 노즐 스캔이 중심에 머무는 시간 차이도 중심 원을 만든다 [33] |
| 원 논문 귀속 | center → 박막 증착 [38] |
| 기본 심각도 | 로트 홀드 검토(`lot_hold`) |
| TEL 장비(모듈) | Tactras / Episode UL 식각: ESC 중심 존, He 존 압력비, VHF 정재파(center-high). Triase+ / Episode / NT333 성막: 샤워헤드 중심, 히터 중심 존. CLEAN TRACK LITHIUS Pro: 도포 노즐 센터링. CELLESTA 단일 세정: 노즐 스캔 프로파일 [1] |
| 타사 장비(인계) | CMP 헤드 중심 존 압력(타사) [2] |
| 고객 측 증거 | 빈 맵 중심 원 반경(`prof0`, `r_med`)과 로트 내 재현. 두께·CD 파라메트릭 맵의 중심 프로파일. 로트 이력(챔버 ID) |
| 장비 측 증거(TEL 엔지니어가 꺼내는 것) | ESC/히터 존별 온도 로그, He 존별 압력 설정·실측. RF 정합기 설정·반사파 로그, 레시피 변경 이력. 샤워헤드 교체·세정 이력. 코터 노즐 센터링 설정·분사 타이밍. 챔버 시즈닝·PM 이력 |
| 점검 순서 | (1) 중심 원의 반경이 ESC/히터 중심 존 반경과 일치하는지(일치하면 존 제어, 아니면 샤워헤드·노즐) (2) 식각: ESC 중심 존 온도·히터, 존별 He 압력 설정(중심/엣지 비) (3) VHF CCP면 정재파 조건 — 정합기 설정·저주파 병용 조건 변경 이력 (4) 성막: 샤워헤드 중심 홀 막힘, 세정 주기 (5) 코터 노즐 센터링·분사 타이밍, 세정 노즐 스캔 |

| 분류기 특징 | `r_std` AUC 0.966, `prof0`(최내측 반경 구간 불량률 비) AUC 0.990. F1(5회) 0.97. RF는 `r_std > 0.27 & axial_c <= 0.17 → CENTER` 처럼 반경을 보지 않고도 CENTER에 도달하는 경로를 갖는다 |

### DONUT — 중간 반경 고리 (donut)

| 항목 | 내용 |
|---|---|
| 모양 | 중심과 가장자리는 살고 중간 반경에 고리 |
| 메커니즘 | 반경 방향 프로파일에 극값이 있다는 뜻이다. 다존 히터나 ESC의 존 경계, 다존 CMP 헤드의 존 경계, 스핀 코팅의 두께 링, 베이크 플레이트 존 경계(추정) [70], 웨이퍼 휨(bow)과 척 접촉이 특정 반경에서 떨어지는 경우. 플라즈마에서는 정재파(center-high)와 스킨 효과(edge-high)가 겹치거나 압력이 높아 중간 반경에 극값이 생길 수 있으나 이는 **2차 효과**다 — 정재파 자체는 CENTER 원인이다 [19] |
| 원 논문 귀속 | (없음) |
| 기본 심각도 | 로트 홀드 검토(`lot_hold`) |
| TEL 장비(모듈) | Tactras / Episode UL 식각: ESC 존 경계, 압력 조건. Triase+ / Episode 단일 웨이퍼 성막: 히터 존 경계. TELINDY PLUS 퍼니스: 존은 보트 축 방향(상/중/하)이므로 한 장의 반경 고리보다 슬롯 위치별 비율 변화로 본다. CLEAN TRACK LITHIUS Pro: 스핀 두께 링, 베이크 플레이트 존(추정) [1] |
| 타사 장비(인계) | CMP 다존 헤드 존 경계(타사) [2] |
| 고객 측 증거 | 고리 반경·폭(`prof2`, `r_std`), 로트 내 재현. 웨이퍼 휨 측정값. 파라메트릭 맵의 반경 프로파일 극값 |
| 장비 측 증거(TEL 엔지니어가 꺼내는 것) | 히터/ESC 존 경계 반경(사양), 존별 온도 설정·로그. RF 압력·주파수 조건과 레시피 변경 이력. 코터 회전수·분사 타이밍 레시피, 베이크 플레이트 존 설정. PM·부품 교체 이력 |
| 점검 순서 | (1) 고리 반경(`r_med`)이 장비 다존 경계(히터/ESC 존 반경)와 일치하는지 — 일치하면 존 간 설정 불일치 (2) 식각: 압력·주파수 조건 변경 이력(2차 효과) (3) 코터: 스핀 두께 링(회전수·분사 타이밍), 베이크 플레이트 존(추정) (4) 휨 측정값과 상관 (5) 타사 CMP 헤드 존 경계면 인계 |
| TEL 원인 vs 타사 인계 | 고리 반경이 TEL 장비 존 경계와 일치하면 TEL 원인. CMP 헤드 존 반경과 일치하고 CMP 직후에만 나오면 타사 인계 |

### SCRATCH — 선형 (scratch)

| 항목 | 내용 |
|---|---|
| 모양 | 얇고 긴 선. 직선 또는 호 |
| 메커니즘 | 기계적 접촉 또는 액체 궤적이다. CMP에서는 웨이퍼와 패드가 모두 회전하므로 패드에 박힌 입자(슬러리 응집체, 컨디셔너 잔해, 리테이닝 링 안쪽 홈의 잔류물)가 남기는 궤적이 흔히 **호(弧) 모양**이고, 반송 중 끌림(로봇 엔드이펙터·핀·카세트 슬롯)은 **직선**인 경우가 많다 — 이것은 **경험칙이지 절대 규칙이 아니다** [28]. 더 확실한 구분은 **로트 안에서 선의 방향·위치가 노치 기준으로 재현되는가**다(핸들링 고정 접촉은 재현, CMP 입자는 무작위) [29]. 코터에서는 중심 지향 방사형 선 군집 ← 레지스트 도포량 부족, 양끝 소용돌이 대각선 ← 디벨로퍼 노즐 오염, EBR 노즐 끝 용제 방울 낙하가 선형 결함을 만든다 [20][21]. 단일 웨이퍼 세정은 노즐 궤적을 따른 호/방사선 [33]. **프로브 카드는 선형 스크래치를 만들지 않는다** — 프로브 쪽 원인은 멀티사이트 카드의 특정 사이트 불량이 터치다운 격자 주기로 반복되는 규칙 패턴이나 척 이동 오프셋으로 평행 이동하는 패턴으로 나타나며, NEAR_FULL과 LOC 행에서 다룬다 [26] |
| 원 논문 귀속 | scratch → 기계 핸들링 [38] |
| 기본 심각도 | 로트 홀드 검토(`lot_hold`) |
| TEL 장비(모듈) | 모든 TEL 장비 공통: EFEM 반송 로봇·엔드이펙터·FOUP 슬롯. CLEAN TRACK LITHIUS Pro: 도포량(중심 지향 방사선), 디벨로퍼 노즐(소용돌이 대각선), EBR 노즐. CELLESTA 단일 세정: 노즐 궤적 호/방사선 [1][20] |
| 타사 장비(인계) | CMP 슬러리 필터·패드·컨디셔너·리테이닝 링 안쪽 홈(타사), CMP 후세정 브러시(타사) [2][27] |
| 고객 측 증거 | 선의 모양(호/직선)·길이·방향, 로트 내 재현(노치 기준). 로트 이력: CMP 직후인가, 어느 반송 경로인가. 웨이퍼 뒷면·엣지 검사 |
| 장비 측 증거(TEL 엔지니어가 꺼내는 것) | EFEM 로봇 티칭·센터링 로그, 엔드이펙터 패드 교체 이력. FOUP/카세트 슬롯 상태, 웨이퍼 핸들링 알람 로그. 코터 도포량·디벨로퍼 노즐 세정 이력, EBR 노즐 상태. 세정기 노즐 스캔 레시피 |
| 점검 순서 | (1) 선이 호인지 직선인지(`wm811k_scratch_shape.py`, 경험칙) 그리고 로트 안에서 방향·위치가 노치 기준으로 재현되는가 (2) 반송계: 엔드이펙터 패드, FOUP/카세트 슬롯 끌림, 웨이퍼 슬립 흔적, 로봇 티칭 로그 (3) 코터: 방사선 군집이면 도포량, 소용돌이면 디벨로퍼 노즐, EBR 노즐 방울 (4) 세정 노즐 궤적 (5) 호 모양이고 CMP 직후 로트에만 나오면 CMP(타사 인계) (6) 격자 주기 반복이면 스크래치가 아니라 LOC/NEAR_FULL의 프로버 항목 |
| TEL 원인 vs 타사 인계 | 로트 안에서 방향·위치가 노치 기준으로 재현되고 TEL 반송 경로와 맞으면 TEL 원인. 호 모양·무작위 위치·CMP 직후면 타사 인계 |
| 분류기 특징 | 전역 통계로는 못 잡는다(`axial_c` AUC 0.682). `elongation`(최대 성분 세장비) AUC 0.930. F1(단일): 트리(전역) 0.319 → 구조 특징 RF 0.765. F1(5회, 20개 특징) 0.83 — 위치 특징이 겨냥하지 않았는데도 올랐다(스크래치는 중심을 지나 무게중심이 안쪽이라 `big_r`이 LOC과의 혼동을 줄였다). `big_len`(최대 성분 주축 길이)은 (가설, 실측 미측정). 코터의 중심 지향 방사선과 핸들링의 접선 방향 직선은 전역 통계로 구분이 안 되므로 '최대 성분 주축의 반경 방향 각도' 특징이 다음 실험이다 |

### LOC — 국소 덩어리 (local)

| 항목 | 내용 |
|---|---|
| 모양 | 가장자리에서 떨어진 한 곳의 덩어리 |
| 메커니즘 | 국소 이벤트다. 챔버 벽의 증착막이 벗겨져 떨어진 파티클 샤워, 웨이퍼 뒷면 파티클(약 150 nm 이상) 때문에 그 위치가 들려 노광 초점이 벗어나는 핫스팟 [24], 국소 오염. **같은 반경에 3점이 120° 간격이면 리프트 핀**(높이·오염) [31]. 같은 결함이 **모든 노광 샷(필드)의 같은 필드 내 좌표에 반복되면 레티클(마스크) 결함**(리피터)이고, 샷 안의 여러 다이에 같은 다이 좌표로 반복되는 것은 레티클이 아니라 **공정 마진(다이 레벨 체계적 결함)**이다 [25]. 샷 피치는 다이 크기의 정수배인데 WM-811K에는 필드 정보가 없어 다이 피치 정수배 주기로만 추정할 수 있다. 프로브 카드의 특정 사이트 불량은 터치다운 격자 주기로 반복된다 [26]. 코터 EBR이 너무 좁으면 엣지 그리퍼 접촉 플레이크가 파티클이 된다 [23] |
| 원 논문 귀속 | (없음) |
| 기본 심각도 | 로트 홀드 검토(`lot_hold`). 먼저 배제: 격자 주기(샷 피치·터치다운 격자) 반복이면 레티클 리피터 또는 프로브 카드 사이트 — 재테스트와 리피터 분석 |
| TEL 장비(모듈) | Tactras / Episode UL, Triase+ / Episode, TELINDY PLUS: 리프트 핀, 챔버 시즈닝·파티클. CLEAN TRACK LITHIUS Pro: EBR 폭·엣지 그리퍼. Precio / Prexa 프로버: 터치다운 격자 주기 반복이면 멀티사이트 카드 특정 사이트 [1][9] |
| 타사 장비(인계) | 레티클·노광기(타사): 샷 피치 리피터. 인라인 검사 장비(타사)의 파티클 추세 [2] |
| 고객 측 증거 | 덩어리 위치(반경·노치 기준 각도)의 로트 내 재현. 격자 주기 반복 여부(리피터 분석). 인라인 파티클 검사 추세(단계별). 뒷면 검사 결과 |
| 장비 측 증거(TEL 엔지니어가 꺼내는 것) | 리프트 핀 높이·교체 이력. 챔버 시즈닝 후 경과 웨이퍼 수, PM 이력, 파티클 알람 로그. 챔버 벽·라이너 교체 이력. EBR 폭 설정, 엣지 그리퍼 상태(코터). 프로버 프로브 카드 사이트별 불량률(격자 반복일 때) |
| 점검 순서 | (1) 덩어리 위치가 로트 안에서 같은가(공정·장비 고정 요소) 다른가(파티클 이벤트) (2) 같은 반경 3점 120°면 리프트 핀 — 노치 기준 각도와 반경(`wm811k_azimuth.py`)으로 어느 TEL 모듈인지 특정 (3) 샷 피치 반복이면 레티클 리피터(노광 인계), 다이 피치 반복이면 공정 마진 (4) 파티클 샤워: 시즈닝 후 경과 웨이퍼 수, PM 직후 파티클 카운트(`wm811k_spc.py --event-col`) (5) 직전 증착·코팅 단계의 뒷면 파티클 검사 (6) 코터 EBR 폭·엣지 그리퍼 |
| TEL 원인 vs 타사 인계 | 위치가 TEL 챔버의 핀 반경·시즈닝 이력과 맞으면 TEL 원인. 샷 피치 반복이면 노광 인계, 터치다운 격자 반복이면 프로버 점검(Precio / Prexa면 TEL 프로버 지원) |
| 분류기 특징 | 가장 어려운 클래스. F1(5회) 0.84. EDGE_LOC과 혼동(5회 합산 542장). `big_r`(최대 성분 무게중심 반경) AUC 0.846, `big_r_min` 0.807로 갈린다. 격자 자기상관(다이 피치 주기) 특징은 다음 실험 |

### RANDOM — 산발 (random)

| 항목 | 내용 |
|---|---|
| 모양 | 위치 구조 없이 흩어진 불량 |
| 메커니즘 | 공정 베이스라인 결함 밀도다. 파티클, 게이트 산화막 결함, 무작위 리소 결함. 위치 구조가 없는 산발 불량은 포아송(균일 무작위) 수율 모델이 **전제하는** 영역이다. 실제 팹 데이터는 군집 때문에 음이항 모델(군집 계수)이 더 맞고, 군집이 있으면 이미 LOC/EDGE_LOC 쪽이다 [30]. 그래서 특정 장비 하나보다 라인 전체 베이스라인 결함 밀도 문제일 가능성이 높다. 세정 장비 전환(배치 ↔ 단일)은 베이스라인 밀도 자체를 바꾼다 — 배치 웻벤치는 엣지 집중·세로 패턴, 단일 스핀 세정은 무작위 밀도 [33]. Certas LEAGA는 무액체라 워터마크가 없다 [3] |
| 원 논문 귀속 | (없음) |
| 기본 심각도 | 모니터링(`monitor`) |
| TEL 장비(모듈) | Tactras / Episode UL, Triase+ / Episode / NT333, TELINDY PLUS: 챔버 시즈닝·파티클(PM 직후). CELLESTA / EXPEDIUS / NS300 세정: 베이스라인 결함 밀도. CLEAN TRACK LITHIUS Pro: 너무 좁은 EBR → 플레이크 [1][10][23] |
| 타사 장비(인계) | 인라인 파티클 검사 장비(타사) 추세가 1차 자료. 라인 전체 청정도(고객 설비) [2] |
| 고객 측 증거 | 웨이퍼별 불량 비율 추세(로트·시각). 단계별 인라인 파티클 검사 추세. 로트 이력(어느 챔버·세정 경로) |
| 장비 측 증거(TEL 엔지니어가 꺼내는 것) | 챔버 파티클 알람 로그, 시즈닝 후 경과 매수. PM·부품 교체 이력(챔버 라이너, 샤워헤드). 세정기 레시피·약액 교체 이력. EBR 폭 설정 |
| 점검 순서 | (1) 불량 비율(`fail_frac`) 자체를 관리도(`wm811k_spc.py`의 FAIL_FRAC_MEAN)에 올린다 — 서서히 오르면 라인 오염, 특정 로트만 높으면 그 로트 이력 (2) 군집이 있으면 이미 LOC/EDGE_LOC — `isolated_frac`으로 확인(가설) (3) 단계별 인라인 파티클 추세(타사 검사 장비)에서 어느 단계가 올랐는지 (4) TEL 챔버: PM 직후·시즈닝 경과 매수에 따른 파티클 (5) 세정 전환 전후 베이스라인 비교 |
| TEL 원인 vs 타사 인계 | 특정 TEL 챔버 통과 로트에서만 밀도가 오르고 그 챔버의 시즈닝·PM 시점과 겹치면 TEL 원인. 모든 경로에서 고르게 오르면 라인 청정도(고객·타사) |
| 분류기 특징 | 설계 가정이 틀렸던 클래스. "작은 성분 수십 개"를 예상했으나 실측은 불량 밀도가 높아 성분이 적고 컸다(`n_comp` AUC 0.155). F1(5회) 0.90. `isolated_frac`(고립 다이 비율)이 그 대안이지만 (가설, 실측 미측정) |

### NEAR_FULL — 전면 (near-full)

| 항목 | 내용 |
|---|---|
| 모양 | 웨이퍼 대부분이 불량 |
| 메커니즘 | 공정 사고 또는 테스트 원인이다. **테스트 쪽 원인을 먼저 배제**한다: 프로브 카드 평탄도·오버드라이브·접촉 저항(CRES), 테스트 프로그램 리밋, 제품/웨이퍼 ID 혼동도 전면 불량으로 찍힌다 [26]. 프로브 팁 이물로 CRES가 오르면 전체 불량이 되고 클리닝 시트·스크럽으로 회복한다. 그 다음이 로트 이력의 비정상 종료 공정: 레시피 오류, 단계 누락, 공정 중 장비 다운. 웨이퍼 파손은 보통 테스트까지 가지 않는다(추정) [34] |
| 원 논문 귀속 | (없음) |
| 기본 심각도 | 라인 정지 판단 필요(`line_stop_review`). 먼저 배제: 재테스트로 테스트 원인 배제 |
| TEL 장비(모듈) | Precio / Prexa 프로버: 프로브 카드 접촉·클리닝·터치다운 카운터 [9]. 모든 TEL 공정 장비: 알람·이벤트 로그, 레시피 중단 기록 [1] |
| 타사 장비(인계) | 테스트 프로그램·테스터(타사). 타사 공정 장비의 비정상 종료 |
| 고객 측 증거 | 재테스트 결과. 같은 로트 다른 웨이퍼의 빈 맵. 로트 이력(비정상 종료·홀드 기록). 테스트 프로그램 버전·리밋 |
| 장비 측 증거(TEL 엔지니어가 꺼내는 것) | 장비 알람·이벤트 로그(해당 로트 처리 시각). 레시피 실행 로그(단계 누락·중단). 프로버: 프로브 카드 CRES·클리닝 시트 주기·터치다운 카운터. 핸들링 알람 로그 |
| 점검 순서 | (1) **재테스트**: 프로브 카드 평탄도·오버드라이브·CRES, 테스트 프로그램 리밋, ID 혼동 배제(Precio / Prexa면 카드 클리닝·터치다운 카운터) (2) 같은 로트의 다른 웨이퍼도 그런가(공정 사고) 한 장만 그런가(단일 웨이퍼 이벤트) (3) 로트 이력에서 비정상 종료 공정 — 장비 알람·이벤트 로그와 대조 (4) 실제 공정 원인으로 확인되면 라인 정지·로트 홀드 판단을 고객 수율팀과 함께(초동 보고) (5) 파손 의심이면 핸들링 알람 로그 |
| TEL 원인 vs 타사 인계 | 재테스트 후에도 전면 불량이고 로트 이력의 비정상 종료가 TEL 장비 알람과 겹치면 TEL 원인. 재테스트로 사라지면 프로브 카드·테스트 프로그램 쪽(Precio / Prexa면 TEL 프로버 지원) |
| 분류기 특징 | `fail_frac` AUC 1.000. 분류기에서 가장 쉬운 클래스. F1(5회) 0.98. 149장으로 가장 드물다. 운영에서는 **재현율 우선** — 놓치면 라인 정지 판단이 늦어지고, 오탐의 비용은 재테스트 1회라 싸다 |

## 오분류의 현장 비용

분류기 오류는 F1 숫자가 아니라 "엔지니어가 어느 로그를 먼저 꺼내느냐"로 비용이 든다. 혼동 쌍마다 잘못 가는 점검과 완화책을 적는다. 혼동 건수는 README 한계 절(5회 합산)과 같다.

| 혼동 쌍 | 잘못 가는 점검 | 낭비·위험 | 완화책 |
|---|---|---|---|
| LOC → EDGE_LOC (5회 합산 542장) | 로봇 센터링·EBR 편심·챔버 비대칭 점검으로 간다 | 실제는 챔버 파티클·리프트 핀·리피터. 로봇 티칭을 건드리면 멀쩡한 반송계를 흔들고, 시즈닝·핀 점검이 늦어진다 | `big_r`·`big_r_min`으로 무게중심 반경 확인, `wm811k_azimuth.py`의 반경·각도 출력, 저신뢰면 사람이 맵을 본다 |
| SCRATCH → LOC (5회 합산 270장) | 국소 파티클 이벤트로 넘겨 반송계·CMP 점검을 건너뛴다 | 끌림 원인(엔드이펙터·슬롯)이 로트마다 반복된다 | `elongation`·`wm811k_scratch_shape.py`로 선형성·모양 확인. 로트 안 방향 재현 여부 |
| EDGE_RING ↔ EDGE_LOC | 전둘레면 엣지 링 소모품·ESC 엣지 존, 한쪽이면 로봇 센터링 | 엣지 링 교체는 챔버 벤트·재인증이 따르는 작업이라(소요 시간은 추정 [68]) 오판하면 가동률 손실이 크다. 반대로 소모품 마모를 핸들링으로 넘기면 링 폭이 계속 넓어진다 | `outer_cover`(각도 커버리지)와 로트 내 반복, `dir_c` |
| CENTER ↔ DONUT | ESC 중심 존 vs 존 경계 설정 | 존 설정을 잘못 건드리면 다음 로트까지 영향 | `prof0`/`prof2` 반경 프로파일, 고리 반경을 장비 존 반경과 대조 |
| RANDOM ↔ CLEAN / LOC | 베이스라인 밀도 상승을 못 보거나(CLEAN), 이벤트로 오해(LOC) | 라인 오염 추세를 놓침 | `fail_frac` 자체를 FAIL_FRAC_MEAN 관리도에 올린다. 패턴 라벨과 무관하게 비율 추세를 본다 |
| NEAR_FULL 미검출 | 전면 불량을 다른 패턴으로 읽어 라인 정지 판단이 늦어진다 | 가장 비싼 오류. 149장으로 드물어 데이터가 적다 | **재현율 우선.** `fail_frac` AUC 1.000이므로 운영에서는 분류기 앞에 `fail_frac` 임계값 하드 룰(규칙 분류기의 NEAR_FULL_FRAC 0.60)을 두고, 오탐 비용은 재테스트 1회로 받아들인다 |
| 패턴 전반의 저신뢰 | 분류기가 헷갈리는 웨이퍼를 자동 조치에 태운다 | 새 패턴 출현·모델 노후를 놓침 | `wm811k_spc.py`의 LOW_CONFIDENCE 관리도(모델을 감시하는 관리도). 임계값은 고정값이 아니라 baseline 분위수(`--conf-quantile`) |

## 맵 하나에서 원인까지 — 현장 순서

고객 에스컬레이션을 받은 장비사 기술지원 엔지니어의 순서다. 각 단계에 이 저장소의 스크립트를 붙였다. WM-811K에는 시각·챔버·슬롯·장비 이력이 없으므로 3~7단계는 합성 데이터로 로직만 확인한 것이며, 실측에서는 로트당 평균 3.2장이라 n 부족이 기본이다.

1. **고객 에스컬레이션 수신.** 받을 것: 빈 맵, 로트 이력(어느 TEL 챔버를 언제 거쳤는가), 재테스트 여부, 인라인 검사 추세. 맵 판정과 조치 플레이북은 `wafer_pattern_classifier.py --actions <PATTERN>`, 로트 묶음 리포트는 `batch_wafer_report.py`. 고객 데이터(로트명·장비 ID)는 저장소에 넣지 않고 리포트는 `--anonymize`로 낸다.
2. **테스트 원인 배제.** NEAR_FULL과 격자 주기 반복 패턴은 프로브 카드·테스트 프로그램이 만들 수 있다. 재테스트가 가장 싸다. 프로버가 Precio / Prexa면 TEL 프로버 쪽 점검(카드 클리닝·터치다운 카운터)이 함께 간다.
3. **로트 안에서 반복되는가.** 같은 패턴이 로트 전체에 있으면 공정 조건이나 장비 상태, 한 장이면 핸들링이나 파티클 이벤트. 배치 장비(TELINDY PLUS 퍼니스, EXPEDIUS 웻벤치)라면 한 장의 모양보다 **보트 슬롯 위치(상/중/하)에 따른 패턴 비율 변화**가 서명이다 — `wm811k_slot.py --pattern <PATTERN>` (waferIndex는 물리 슬롯의 대리 변수 [46]).
4. **노치 기준 방위각 / 스크래치 모양 / 슬롯.** EDGE_LOC·LOC은 `wm811k_azimuth.py`로 노치 기준 각도를 재서 로트 안 각도가 고정인지(챔버 고정 요소) 흩어지는지(핸들링) 본다. SCRATCH는 `wm811k_scratch_shape.py`로 호/직선과 로트 안 방향 재현을 본다. 배치 장비는 `wm811k_slot.py`.
5. **장비 측 증거 대조.** 패턴 표의 '장비 측 증거' 행 — 알람/이벤트 로그, 부품 누적 카운터(엣지 링 RF 시간, 시즈닝 후 매수), 레시피 변경 이력, PM·부품 교체 기록, 로봇 티칭/센터링 로그, ESC He 압력·존 온도 로그 — 를 해당 로트 처리 시각에 맞춰 꺼낸다. `ACTION_DETAIL[pattern]["tool_evidence"]`가 목록이다.
6. **공통성 분석.** 불량 로트들이 공유한 장비·챔버를 이력에서 찾는다 — `wm811k_commonality.py --history lot_history.csv --pattern <PATTERN>` (이력 스키마는 [`lot_history_schema.md`](lot_history_schema.md)). 한 챔버로 좁혀지면 그 챔버의 부품 교체·레시피 변경·PM 시점을 본다. 라우팅이 묶여 있으면 혼입 경고를 함께 읽는다.
7. **언제부터인가.** 패턴 비율을 관리도에 올려 추세의 시작점을 찾고, 부품 교체·PM 이벤트를 세로선으로 겹친다 — `wm811k_spc.py <pred.csv> --time-col <t> --event-col <event> --group-col chamber`. 시작점이 교체·PM과 겹치면 그것이 답이다. 알람이 난 패턴에는 `ACTION_DETAIL`의 점검 순서가 붙는다.
8. **TEL 원인 / 타사 인계 판정.** 각 패턴 표의 'TEL 원인 vs 타사 인계' 행(`ACTION_DETAIL[pattern]["handoff"]`)으로 판정한다. CMP·노광 스캐너·레티클·독립 검사 장비·테스터는 TEL 범위 밖이므로 [2] 근거(로트 이력에서 그 단계 직후에만 생김, 샷 피치 반복 등)와 함께 고객에게 넘긴다.
9. **보고.** 초동(현상·영향 범위·임시 조치) → 중간(배제한 것·남은 가설) → 종결(근본 원인·시정 조치·재발 방지·관리도 복귀 확인). 보고 양식과 협업 구조는 [`handoff.md`](handoff.md), 끝까지 수행한 합성 사례는 [`case_study_8d.md`](case_study_8d.md)(두 문서 모두 합성 시나리오).

## 이 저장소와의 연결

- `wafer_pattern_classifier.ACTION_DETAIL`은 위 표의 '점검 순서'·'고객 측 증거'·'장비 측 증거'·'TEL 장비'·'타사 인계'·'판정' 행의 단일 소스다. `ACTIONS`(한 줄 요약)는 거기서 생성되며 `batch_wafer_report.py`와 `wm811k_spc.py`의 알람 출력에 붙는다. `tests/test_actions.py`가 공정 물리 교정(NEAR_FULL 재테스트 우선, 정재파는 CENTER, 프로브 카드는 선형 아님, 리프트 핀은 LOC, '중심 누설' 없음)과 제품명 현행 표기를 코드 쪽에서 고정한다.
- `wm811k_spc.py`는 7번 단계다. 패턴별 p 관리도(Laney 과산포 보정 [35]), 저신뢰 비율 관리도, EWMA, Western Electric 규칙에 `--event-col`(부품 교체·PM 세로선)과 `--group-col`(챔버·슬롯 층화)을 더했다.
- `wm811k_azimuth.py`, `wm811k_scratch_shape.py`, `wm811k_slot.py`, `wm811k_commonality.py`는 3·4·6번 단계다. 모두 합성 데이터로 로직만 확인했다.
- 표의 '분류기 특징' 행은 README의 진단 과정과 같은 숫자이며 출처(AUC / F1 5회 / F1 단일 / 가설)를 구분해 적었다. 어떤 특징이 어떤 물리 현상을 재고 있는지가 이 프로젝트에서 해석 가능성을 고집한 이유다.
- 장비군별 소모품·PM 항목과 TEL 소프트웨어(TELeMetrics, Ingenio)와의 결합 지점은 [`tel_equipment_map.md`](tel_equipment_map.md), 공정 단계·서브시스템·안전 맥락은 [`process_context.md`](process_context.md), 한/영/일 용어는 [`glossary.md`](glossary.md).

TEL 현행 제품(tel.com 제품 목록, 2026-10 확인 [1])으로는 코터/디벨로퍼 CLEAN TRACK LITHIUS Pro 계열, 플라즈마 식각 Tactras / Episode UL, 가스 화학 식각 Certas LEAGA, 배치 퍼니스 TELINDY PLUS, 단일 웨이퍼 성막 Triase+ / Episode / NT333, 세정 CELLESTA / EXPEDIUS / NS300, 웨이퍼 프로버 Precio / Prexa, 본더 Synapse가 각각 해당한다. CMP, 노광 스캐너, 독립 검사 장비는 TEL 제품 목록에 없으므로 [2] 그 항목은 고객 라인의 타사 장비 몫이며 '인계'로 적었다. 특정 제품의 내부 구조를 전제로 쓴 내용은 없다.
