# 웨이퍼 맵 결함 시그니처와 장비 원인

웨이퍼 맵의 불량 분포는 공정 어딘가의 비대칭을 그대로 찍어낸 것이다. 반경 방향으로 대칭이면 회전 대칭인 장비 요소(척, 샤워헤드, 스핀 척, 플라즈마)를, 방위각 한쪽에 치우치면 비대칭 요소(로봇 핸드오프, 배기구, 리프트 핀)를, 선이면 기계적 접촉을 먼저 의심한다. 이 문서는 분류기가 내는 8종 패턴마다 "왜 그 모양이 나오는가"와 "현장에서 무엇부터 보는가"를 적는다.

주의할 점이 둘 있다. WM-811K는 웨이퍼 테스트의 빈 맵이라 모든 공정 단계의 결과가 누적된 것이다. 따라서 아래 표는 확정이 아니라 **의심 순서**다. 그리고 같은 모양이라도 로트 전체에 나오면 공정 조건, 한 장에만 나오면 핸들링이나 파티클 이벤트일 가능성이 높다. 원인 특정은 맵 하나가 아니라 로트 이력과 공통성 분석에서 끝난다.

## 패턴별 정리

### EDGE_RING — 외곽 전둘레

| 항목 | 내용 |
|---|---|
| 모양 | 웨이퍼 가장자리를 따라 띠 모양으로 불량. 방위각 전체에 고르게 분포 |
| 메커니즘 | 웨이퍼 가장자리는 모든 회전 대칭 공정에서 경계 조건이 바뀌는 곳이다. 플라즈마 식각에서는 시스(sheath)가 웨이퍼 끝에서 휘어 이온 입사각과 식각률이 달라진다. 이를 보정하는 부품이 엣지 링(포커스 링)인데 소모품이라 마모되면 보정이 틀어진다. CVD에서는 히터 가장자리 온도 강하와 가스 체류 시간 차이로 막 두께가 달라진다. 정전척(ESC)은 바깥 존의 He 백사이드 냉각이 약해지면 가장자리 온도가 뜬다. CMP는 리테이닝 링 마모로 가장자리가 과연마된다. 코터는 EBR(엣지 비드 제거) 폭이 넓으면 가장자리 다이가 통째로 죽는다 |
| 의심 장비 | 식각기(엣지 링, ESC 바깥 존), CVD/ALD(히터 엣지, 샤워헤드 외곽), CMP(리테이닝 링), 코터(EBR) |
| 점검 | 엣지 링 누적 RF 시간과 높이, ESC 존별 온도와 He 압력, 센터/엣지 가스 분배비, EBR 폭 설정, 리테이닝 링 교체 주기. 링 폭이 서서히 넓어지면 마모, 로트 사이에 갑자기 생기면 부품 교체나 레시피 변경 시점을 본다 |
| 분류기 특징 | r_mean 0.956 AUC, outer_cover(외곽 각도 커버리지) 높음. EDGE_LOC과는 커버리지로 갈린다 |

### EDGE_LOC — 외곽 국소

| 항목 | 내용 |
|---|---|
| 모양 | 가장자리 한쪽 구간(호)에만 불량 |
| 메커니즘 | 회전 대칭이 깨진 것이므로 방위각 의존 요소를 본다. 로봇이 웨이퍼를 척 중심에서 어긋나게 놓으면 한쪽 가장자리가 엣지 링에 가깝거나 멀어진다. 리프트 핀이나 클램프 한 곳의 접촉 불량, 배기 포트 방향의 유동 비대칭, 가스 주입구 위치, 노치 정렬 오류도 같은 모양을 만든다. 가장자리 한 점의 치핑(깨짐)이면 그 주변이 호 모양으로 죽는다 |
| 의심 장비 | 반송 로봇(티칭, 센터링), 식각/CVD 챔버의 비대칭 요소(배기, 리프트 핀), 얼라이너 |
| 점검 | 불량 호의 방위각을 노치 기준으로 재서 챔버 도면의 배기구·가스구 위치와 맞춰본다. 같은 챔버를 거친 웨이퍼에서 같은 각도면 챔버 비대칭, 각도가 제각각이면 핸들링. 로봇 센터링 오프셋 로그, 리프트 핀 높이, 웨이퍼 엣지 검사 |
| 분류기 특징 | r_mean 높고 dir_c(방향 집중도) 높음. big_edge_touch(최대 성분이 가장자리에 닿은 비율)로 LOC과 구분 |

### CENTER — 중심부

| 항목 | 내용 |
|---|---|
| 모양 | 중심 원반 영역에 불량 |
| 메커니즘 | 가장자리의 반대로, 회전 대칭 공정의 중심 조건이다. ESC 중심 존 온도, He 백사이드 중심 누설, 샤워헤드 중심 홀 막힘, 플라즈마 밀도가 중심에서 봉우리를 이루는 조건, CMP 헤드 중심 존 압력, 스핀 코팅의 중심 두께(노즐 위치와 분사 타이밍). 세정기에서는 노즐 스캔이 중심에서 머무는 시간이 다르다 |
| 의심 장비 | ESC/히터 다존 제어, 샤워헤드, CMP 헤드 존 압력, 코터 노즐 |
| 점검 | 존별 온도 로그, He 유량과 압력, 샤워헤드 세정 주기, 노즐 센터링. 중심 원의 반경이 ESC 중심 존 반경과 맞는지 |
| 분류기 특징 | r_std 0.966 AUC, prof0(최내측 반경 구간 불량률 비) 0.990 |

### DONUT — 중간 반경 고리

| 항목 | 내용 |
|---|---|
| 모양 | 중심과 가장자리는 살고 중간 반경에 고리 |
| 메커니즘 | 반경 방향 프로파일에 극값이 있다는 뜻이다. 다존 히터나 ESC의 존 경계, 다존 CMP 헤드의 존 경계, RF 정재파 효과(고주파에서 파장이 웨이퍼 크기와 비슷해지며 특정 반경에 전력 봉우리), 스핀 코팅의 두께 링, 웨이퍼 휨(bow)과 척 접촉이 특정 반경에서 떨어지는 경우 |
| 의심 장비 | 다존 제어 경계(히터, ESC, CMP 헤드), RF 매칭, 코터 스핀 조건 |
| 점검 | 고리 반경이 장비 존 경계와 일치하는지, RF 매칭 로그, 웨이퍼 휨 측정값과 상관 |
| 분류기 특징 | prof2(중간 구간 불량률 비) 0.980, r_med 중간, r_std 작음 |

### SCRATCH — 선형

| 항목 | 내용 |
|---|---|
| 모양 | 얇고 긴 선. 직선 또는 호 |
| 메커니즘 | 기계적 접촉이다. CMP에서 슬러리 응집체나 패드 컨디셔너 잔해가 웨이퍼를 긁으면 패드 회전 때문에 **호(弧) 모양**이 된다. 로봇 엔드이펙터나 핀, 카세트 슬롯에서 웨이퍼가 끌리면 **직선**이다. 웨이퍼 테스트의 프로브 카드가 긁은 자국도 선형이다. 선의 모양이 곧 원인 구분이다 |
| 의심 장비 | CMP(슬러리 필터, 패드, 컨디셔너, 후세정 브러시), 반송 로봇과 카세트, 프로버 |
| 점검 | 선이 호인지 직선인지, 길이와 방향이 로트 안에서 반복되는지. CMP 슬러리 필터 교체 이력, 패드 수명, 엔드이펙터 패드 상태, 웨이퍼 슬립 흔적 |
| 분류기 특징 | 전역 통계로는 못 잡는다(axial_c AUC 0.682). elongation(최대 성분 세장비) 0.930, big_len. 구조 특징 추가 후 F1 0.32에서 0.77로, 위치 특징 후 0.83 |

### LOC — 국소 덩어리

| 항목 | 내용 |
|---|---|
| 모양 | 가장자리에서 떨어진 한 곳의 덩어리 |
| 메커니즘 | 국소 이벤트다. 챔버 벽의 증착막이 벗겨져 떨어진 파티클 샤워, 웨이퍼 뒷면 파티클 때문에 그 위치가 들려 노광 초점이 벗어나는 경우(핫스팟), 국소 오염. 같은 위치가 다이 격자 간격으로 반복되면 레티클 결함이다 |
| 의심 장비 | 파티클 발생원(챔버 시즈닝 주기, 벽 박리), 노광기 초점(뒷면 파티클), 레티클 |
| 점검 | 덩어리 위치가 로트 안에서 같은가(공정) 다른가(이벤트). 다이 격자로 반복되면 레티클 검사. 파티클 카운트 추세, 챔버 시즈닝 후 경과 웨이퍼 수 |
| 분류기 특징 | 가장 어려운 클래스. EDGE_LOC과 혼동(5회 합산 542장). big_r(최대 성분 무게중심 반경) 0.846, big_r_min 0.807로 갈린다 |

### RANDOM — 산발

| 항목 | 내용 |
|---|---|
| 모양 | 위치 구조 없이 흩어진 불량 |
| 메커니즘 | 공정 베이스라인 결함 밀도다. 파티클, 게이트 산화막 결함, 무작위 리소 결함. 수율이 포아송 모델을 따르는 영역이라 특정 장비 하나가 아니라 전체 라인의 청정도 문제다 |
| 의심 장비 | 특정하기 어렵다. 단계별 파티클 검사(인라인 검사 장비) 추세에서 어느 단계가 올랐는지 본다 |
| 점검 | 불량 비율 자체를 관리도에 올린다. 비율이 서서히 오르면 라인 오염, 특정 로트만 높으면 그 로트의 이력 |
| 분류기 특징 | 설계 가정이 틀렸던 클래스. "작은 성분 수십 개"를 예상했으나 실측은 불량 밀도가 높아 성분이 적고 컸다(n_comp AUC 0.155). isolated_frac(고립 다이 비율)이 그 대안 |

### NEAR_FULL — 전면

| 항목 | 내용 |
|---|---|
| 모양 | 웨이퍼 대부분이 불량 |
| 메커니즘 | 공정 사고다. 레시피 오류, 단계 누락, 공정 중 장비 다운, 웨이퍼 파손. 단, **테스트 쪽 원인을 먼저 배제**해야 한다. 프로브 카드 접촉 불량이나 테스트 프로그램 오류도 전면 불량으로 찍힌다 |
| 의심 장비 | 먼저 프로버와 테스트 프로그램, 그 다음 로트 이력에서 비정상 종료된 공정 |
| 점검 | 같은 로트의 다른 웨이퍼도 그런가(공정) 한 장만 그런가(핸들링·파손). 재테스트로 테스트 원인 배제. 실제면 라인 정지 판단 |
| 분류기 특징 | fail_frac AUC 1.000. 분류기에서 가장 쉬운 클래스. 149장으로 가장 드물다 |

## 맵 하나에서 원인까지 — 현장 순서

1. **테스트 원인 배제.** NEAR_FULL과 SCRATCH는 프로브 카드와 테스트 프로그램이 만들 수 있다. 재테스트가 가장 싸다.
2. **로트 안에서 반복되는가.** 같은 패턴이 로트 전체에 있으면 공정 조건이나 장비 상태, 한 장이면 핸들링이나 파티클 이벤트다. 배치 장비(퍼니스)라면 슬롯 위치와의 상관을 본다.
3. **방위각을 노치 기준으로 잰다.** EDGE_LOC과 LOC에서 각도가 챔버의 비대칭 요소(배기, 가스구, 리프트 핀) 위치와 맞으면 그 챔버다.
4. **공통성 분석.** 불량 로트들이 공유한 장비와 챔버를 이력에서 찾는다. 한 챔버로 좁혀지면 그 챔버의 부품 교체, 레시피 변경, PM 시점을 본다.
5. **언제부터인가.** 패턴 비율을 관리도(`wm811k_spc.py`)에 올려 추세의 시작점을 찾는다. 시작점이 부품 교체나 PM과 겹치면 그것이 답이다.

## 이 저장소와의 연결

- `wafer_pattern_classifier.py`의 `ACTIONS`는 위 표의 점검 항목을 한 줄로 줄인 것이다. 배치 리포트와 SPC 알람 출력에 붙는다.
- `wm811k_spc.py`는 5번 단계다. 패턴 비율의 추세 변화와 분류기 저신뢰 비율을 감시한다.
- 표의 "분류기 특징" 행은 README의 진단 과정과 같은 숫자다. 어떤 특징이 어떤 물리 현상을 재고 있는지가 이 프로젝트에서 해석 가능성을 고집한 이유다.

## 참고

- 공정 장비 분류는 일반적인 팹 구성(식각, CVD/ALD, 퍼니스, 코터/디벨로퍼, 세정, CMP, 노광, 프로버)을 따른다. TEL 제품으로는 식각기 Tactras, CVD Trias, 퍼니스 Telindy, 코터/디벨로퍼 Lithius 계열이 각각 해당한다. 특정 제품의 내부 구조를 전제로 쓴 내용은 없다.
