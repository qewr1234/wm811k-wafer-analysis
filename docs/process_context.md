# 공정·장비 맥락 — 8대 공정, 장비 서브시스템, 현장 점검 전 체크리스트

> 한 줄 요약: 웨이퍼 테스트 빈 맵은 모든 공정 단계의 결과가 누적된 것이다. 이 문서는 (1) 8대 공정 각 단계가 맵에 남기는 시그니처와 그것을 재는 이 저장소의 특징, (2) 장비 서브시스템 6개의 이상이 만드는 패턴, (3) 현장 점검 전 안전·클린룸 체크리스트를 적는다. 장비 서술은 공개 자료 수준이며 TEL 내부 구조·매뉴얼은 모른다.

읽는 순서: 맵 한 장을 받으면 ④(누적 결과라는 사실)를 전제로 ①에서 "어느 단계가 이런 모양을 만드는가"를 좁히고, 장비가 특정되면 ②에서 "그 장비의 어느 서브시스템 로그를 꺼내는가"로 내려간다. 실제로 장비 앞에 가기 전에는 ③을 거친다. 패턴별 상세는 [`defect_signatures.md`](defect_signatures.md), 장비군별 소모품은 [`tel_equipment_map.md`](tel_equipment_map.md), 조치 순서의 단일 소스는 `wafer_pattern_classifier.ACTION_DETAIL`이다.

## ① 8대 공정과 웨이퍼 맵 시그니처

'8대 공정'은 국내에서 통용되는 구분(웨이퍼 제조 → 산화 → 포토 → 식각 → 박막(증착·이온 주입) → 금속 배선 → EDS → 패키징)을 따랐고, 세정은 거의 모든 단계 사이에 들어가므로 별도 행으로 뒀다. TEL 장비군은 tel.com 현행 제품명(2026-10 확인) 기준이고, TEL이 만들지 않는 장비는 '타사'로 표시했다.

| 단계 | 대표 TEL 장비군 (타사 장비는 괄호) | 이 단계가 빈 맵에 남기는 시그니처 | 이 저장소의 어떤 특징이 그것을 재는가 |
|---|---|---|---|
| 웨이퍼 제조 (잉곳·가공) | 해당 없음(타사) | 웨이퍼 자체 결함은 대개 입고 검사에서 걸러진다. 휨(bow)은 뒤 단계에서 척 접촉 불량(DONUT)으로 나타날 수 있다 | 직접 재는 특징 없음. 휨 측정값과의 상관은 외부 데이터 |
| 산화·확산·열처리 (배치) | TELINDY PLUS, TELINDY PLUS IRad, EVAROS | 한 장의 모양보다 **보트 슬롯 위치(상/중/하)에 따른 패턴 비율 변화**. 슬롯 번호에 따라 EDGE_RING 폭이 단조 변하면 존별 온도·가스 고갈 구배. 보트 슬롯 파티클 → LOC | `r_mean`, `outer_cover`, `outer_rate`(링 폭)를 슬롯별로 층화: `wm811k_spc.py --group-col slot`, `wm811k_slot.py`(waferIndex를 슬롯 대리 변수로; 물리 슬롯과 같다는 보장 없음 - 추정) |
| 포토 - 코팅·현상 | CLEAN TRACK LITHIUS Pro 계열 | EBR 폭 레이어별 불일치 → **EDGE_RING**; EBR 편심 → **EDGE_LOC**; 도포 노즐 센터링·분사 타이밍 → **CENTER**; 스핀 두께 링·베이크 플레이트 존 경계(추정) → **DONUT**; 중심 지향 방사형 선 군집(레지스트 공급 부족)·양끝 소용돌이 대각선(디벨로퍼 노즐 오염) → 전역 통계로는 **SCRATCH**와 구분 안 됨; 너무 좁은 EBR → 엣지 그리퍼 플레이크 → **RANDOM/LOC** | `r_mean`·`outer_cover`(EDGE_RING), `dir_c`·`big_edge_touch`(EDGE_LOC; big_edge_touch는 실측 미측정 가설), `r_std`·`prof0`(CENTER), `prof2`(DONUT), `elongation`·`big_len`(선). 방사선 vs 접선 방향 선을 가르는 '반경 방향 각도' 특징은 다음 실험 |
| 포토 - 노광 | (노광 스캐너·레티클: 타사) | 레티클 결함은 **샷(노광 필드) 피치**로 반복되는 리피터(LOC). 다이 피치 반복은 레티클이 아니라 공정 마진(다이 레벨 체계적 결함). 뒷면 파티클 → 국소 디포커스 핫스팟(LOC) - 뒷면 파티클을 만든 직전 증착·코팅 단계가 TEL 장비일 수 있음 | `big_r`, `big_r_min`(LOC 위치). 격자 주기 자기상관은 다음 실험. WM-811K에는 필드 정보가 없어 다이 피치 정수배 주기로만 추정 |
| 식각 (플라즈마) | Tactras, Episode UL | 엣지 링 마모 → 시스 왜곡 → 엣지 식각률 변화·이온 틸트 → **EDGE_RING**; ESC 엣지 존 온도·He 압력(엣지 실 밴드 누설) → EDGE_RING; ESC 중심 존·존별 He 압력비·VHF 정재파(center-high) → **CENTER**; 정재파+스킨 효과 겹침·고압력 → **DONUT**(2차); 배기·가스 주입 비대칭 → **EDGE_LOC**(로트 안 같은 각도); 리프트 핀 → 같은 반경 3점(LOC); PM 직후 파티클 → RANDOM/LOC. 원 논문(Wu, Jang & Chen 2015)은 ring 패턴을 식각에 귀속('원 논문 귀속') | `r_mean`(AUC 0.956)·`outer_cover`(0.808)·`outer_rate`(EDGE_RING), `r_std`(0.966)·`prof0`(0.990)(CENTER), `prof2`(0.980)(DONUT), `dir_c`(EDGE_LOC) |
| 식각 (가스 화학) | Certas LEAGA | 무액체·무플라즈마 등방성 식각. 워터마크 없음(공식 특징). 플라즈마 계열 서명(엣지 링·정재파) 해당 없음, 파티클만 공통 | `isolated_frac`, `fail_frac` 추세 |
| 박막 - 증착 (단일 웨이퍼) | Triase+ Ti/TiN, Triase+ W, Episode 1 / 2 DMR, NT333(ALD), EXIM / LEXIA-EX(PVD) | 샤워헤드 중심 홀 막힘·히터 중심 존 → **CENTER**; 다존 히터 존 경계 → **DONUT**; 히터 엣지 온도 강하·센터/엣지 가스비 → **EDGE_RING**; 챔버 벽 박리 파티클 샤워 → **LOC/RANDOM**(시즈닝 후 경과 매수). 원 논문 귀속: center → 박막 증착 | `prof0`·`r_std`(CENTER), `prof2`(DONUT), `r_mean`(EDGE_RING), `n_comp_sig`·`isolated_frac`(파티클; 실측 미측정) |
| 박막 - 이온 주입 | 해당 없음(타사) | 주입 균일도 이상은 보통 전기 특성(파라메트릭)으로 먼저 보이고 빈 맵에는 넓은 반경 대칭 패턴으로 늦게 나타난다(일반론, 추정) | 파라메트릭 맵(`plotly_wafer_heatmap.py`)이 먼저 |
| 금속 배선 (CMP 포함) | Triase+ W / Ti/TiN(배리어·플러그), (CMP: 타사) | CMP 리테이닝 링 마모 → 엣지 제거율이 중심과 달라짐(과연마·저연마 모두) → **EDGE_RING**; 링 안쪽 홈 마모 → 슬러리 잔류물 → **SCRATCH**(호 모양, 무작위 위치 - 경험칙); 다존 헤드 → CENTER/DONUT. 모두 타사 인계 항목 | `elongation`·`big_len`(SCRATCH), 호/직선 적합은 `wm811k_scratch_shape.py`(합성 로직 확인) |
| 세정 | CELLESTA-i / CELLESTA MS2(단일), EXPEDIUS-i(배치), NS300(스크러버) | 배치 웻벤치: 엣지 집중·세로 패턴. 단일 스핀 세정: 고정 서명 없이 무작위 밀도(RANDOM) 변화, 노즐 궤적 호/방사선. 세정 전환 전후 베이스라인 결함 밀도 비교 | `fail_frac`의 I-MR 관리도(FAIL_FRAC_MEAN), `isolated_frac` |
| EDS (웨이퍼 테스트) | Precio XL / Precio octo / Prexa 프로버 (+ 테스터·테스트 프로그램: 타사) | **NEAR_FULL**: 프로브 카드 평탄도·오버드라이브·접촉 저항, 테스트 프로그램 리밋, 제품/웨이퍼 ID 혼동 → 재테스트로 먼저 배제. 멀티사이트 카드 특정 사이트 불량 → **터치다운 격자 주기 반복**, 척 이동 오프셋 → 평행 이동. 프로브 카드의 정상 터치다운은 선형 SCRATCH를 만들지 않는다(예외: 프로버 Z축·인덱스 이상으로 니들이 끌리면 다이 격자 축에 평행한 직선 → 프로버 Z·인덱스 로그 [26]) | `fail_frac`(AUC 1.000, NEAR_FULL). 격자 주기 특징은 다음 실험. WM-811K에는 사이트·터치다운 정보가 없다 |
| 패키징 | Synapse(본더) - 범위 밖 | 빈 맵 이후 단계라 이 저장소 패턴과 직접 연결 없음 | - |

'어떤 특징이 재는가' 열의 AUC는 README 진단 과정의 실측값(WM-811K)이고, `big_edge_touch`·`isolated_frac`·`n_comp_sig`는 `wm811k_improve.py`의 실측 미측정 가설이다. 호/직선 적합·슬롯 검정은 합성 데이터로 로직만 확인했으며 성능이 아니다.

## ② 장비 서브시스템 6개와 이상이 만드는 패턴

TEL Etching FE 경력 공고가 요구하는 '장비 구조 및 진공·RF·플라즈마·가스·반송계 이해'(공고 문구 [53][54])를 축으로, 서브시스템별로 "무엇이 틀어지면 맵에 무엇이 남는가"와 "TEL 엔지니어가 꺼내는 장비 측 증거"를 적는다. 내부 구조는 일반적 단일 웨이퍼 진공 장비 기준이며 특정 제품을 전제하지 않는다.

| 서브시스템 | 구성 요소 (일반) | 이상 → 맵 패턴 | 장비 측 증거 (TEL 엔지니어가 꺼내는 것) |
|---|---|---|---|
| 진공 | 드라이 펌프·터보 펌프, 게이트 밸브, 압력 게이지, 리크 | 압력 상승 → 플라즈마 분포 변화(정재파/스킨 겹침 → **DONUT**, 2차 효과); 미세 리크·펌프 역류 파티클 → **RANDOM/LOC**; 벤트/펌프다운 중 파티클 → PM 직후 RANDOM | 압력 로그·펌프다운 시간 추세, 리크 체크 기록, 벤트 횟수 |
| RF·플라즈마 | RF 전원·정합기, 상부/하부 전극, 엣지 링(포커스 링), 시스 | 엣지 링 마모 → 시스 왜곡 → **EDGE_RING**(이온 틸트 동반); RF 주파수 구성(VHF/LF)·전력·압력 조건과 전극 하드웨어 → **CENTER**(VHF 정재파 center-high; 정합기는 정재파 손잡이가 아니다 [19]); 정합 이상·반사파 증가 → 전력 전달 이상(균일도 전반) | 엣지 링 누적 RF 시간·전력 카운터, 링 높이 보정·엣지 DC 바이어스 보정값 이력, RF 주파수 구성·전력·압력 레시피 변경 이력, 상부 전극 교체 이력, 정합기 위치·반사파 로그(전력 전달 확인용) |
| 가스 분배 | MFC, 샤워헤드(상부 전극), 센터/엣지 분배비, 배기 포트 | 샤워헤드 중심 홀 막힘 → **CENTER**; 센터/엣지 비 이탈 → **EDGE_RING** 또는 CENTER; 배기·주입 위치 비대칭 → **EDGE_LOC**(로트 안 같은 각도, 챔버 도면과 대조) | MFC 유량 로그·교정 기록, 센터/엣지 비 설정값, 샤워헤드 세정·교체 이력, 챔버 도면(배기구·가스구 방위각) |
| 온도·ESC | 다존 히터, ESC 존별 He 백사이드 압력, 엣지 실 밴드·존 간 내측 실 밴드, 리프트 핀 홀 | 중심 존 온도·존별 He 압력비, 중심 존 He 존 간 크로스토크(내측 실 마모)·He 홀 막힘 → **CENTER**; 엣지 존·엣지 실 밴드 He 외부 누설 → **EDGE_RING**; 존 경계 → **DONUT**; 리프트 핀 홀 누설·핀 높이 → **LOC**(같은 반경 3점, 120°) [18] | 존별 온도 로그, He 존 압력 설정·실측·유량·누설률(중심 존이 설정 압력을 못 잡는지), 실 밴드 교체 기록, 리프트 핀 높이·교체 이력 |
| 반송 로봇 | EFEM 로봇·엔드이펙터, 진공 로봇, 얼라이너, 로드포트·FOUP, 리프트 핀 핸드오프 | 센터링 오프셋 → **EDGE_LOC**(웨이퍼마다 제각각 각도); 노치 정렬 오류 → 같은 패턴이 웨이퍼마다 다른 각도; 엔드이펙터 끌림·FOUP 슬롯 → **직선 SCRATCH**(로트 안 노치 기준 재현); 엣지 치핑 → 한 점 주변 호 | 로봇 티칭·센터링 오프셋 로그, 얼라이너 노치 검출 로그, 핸들링 알람 로그, 엔드이펙터 패드 교체 이력 |
| 인터락·알람 | 레시피 실행기, 인터락 조건, 알람·이벤트 로그, 단계 중단/재개 | 레시피 중단·단계 누락·장비 다운 → **NEAR_FULL**(단, 재테스트로 테스트 원인 먼저 배제); 알람 시각이 패턴 비율 변화 시작점과 겹치는지가 '언제부터인가'의 기준 | 알람·이벤트 로그(해당 로트 처리 시각), 레시피 실행 로그, 홀드·재개 기록. `wm811k_spc.py --event-col`의 입력 |

서브시스템 공통: 어떤 로그를 꺼내든 **고객 측 증거(빈 맵·로트 이력·재테스트·인라인 검사 추세)와 같은 시간축**에 놓아야 의미가 있다. `wm811k_spc.py`의 `--time-col`(시각)·`--event-col`(PM·교체 이벤트)·`--group-col`(챔버·슬롯)이 그 자리다.

## ③ 현장 점검 전 안전·클린룸 체크리스트

장비 앞에 가기 전 확인 11줄. 일반적 반도체 장비 안전·클린룸 관행 수준이며 고객사·장비별 절차가 우선한다. SEMI S2는 반도체 장비의 환경·건강·안전(EHS) 지침, SEMI S8은 인간공학 지침이라는 수준으로만 안다(본문 미열람).

1. **작업 허가**: 고객 설비 담당자의 작업 허가서·작업 범위 승인, 해당 장비의 생산 상태(SEMI E10 상태) 확인 후 엔지니어링/정지 상태로 전환 합의.
2. **LOTO(Lock-Out/Tag-Out)**: 전원·가스·공압 차단 후 잠금·표찰. 본인 자물쇠, 본인 열쇠.
3. **RF off 확인**: RF 전원 차단·인터락 확인, 정합기·전극 잔류 전하 방전 후 접근. 고전압(ESC 척킹 전압 포함) 표시 확인.
4. **가스 라인 퍼지**: 공정 가스·약액 라인 퍼지 완료 확인, 가스 캐비닛·누설 감지기 상태 정상. 독성·부식성·가연성 가스 종류와 비상 대응 위치 숙지.
5. **진공·온도**: 챔버 벤트 완료(대기압), 히터·퍼니스·베이크 플레이트가 안전 온도까지 식었는지 확인.
6. **약액**: 세정기·트랙의 산·알칼리·용제 라인 상태, 보안경·내화학 장갑, 세안기 위치.
7. **클린룸 복장**: 방진복(가운)·후드·마스크·장갑·부츠 착용 순서 준수, 에어샤워 통과.
8. **반입 금지 물품**: 일반 종이·목재·일반 필기구·화장품·휴대폰 등 고객 규정의 반입 금지 품목 확인, 공구·부품은 클린룸용 포장.
9. **파티클 발생 행동 금지**: 빠른 동작, 웨이퍼·FOUP 위로 손 넘기기, 장비 위 물건 올리기 금지. 클린룸 클래스(ISO 14644-1)에 맞는 행동 기준 확인.
10. **작업 기록**: 작업 전 장비 상태·알람 로그 캡처, 교체 부품의 누적 카운터 값 기록(작업 후 리셋 전에), 작업지시서에 시각·내용 기입. 고객 데이터(로트명·레시피)는 허가 범위 밖으로 반출하지 않는다([`handoff.md`](handoff.md) 기밀 원칙).
11. **비상**: 비상 정지(EMO) 버튼·소화기·대피 경로 위치 확인.

## ④ EDS 빈 맵은 모든 단계의 누적 결과다

WM-811K는 다이 단위 pass/fail 맵(사실상 웨이퍼 테스트 빈 맵)이다 [38][43]. 빈 맵은 공정의 마지막(EDS)에서 한 번 찍히므로, 위 ①의 모든 단계가 남긴 비대칭이 겹쳐서 보인다. 따라서:

- 패턴 → 단계의 대응은 **의심 순서**이지 확정이 아니다. 같은 EDGE_RING이 식각 엣지 링, 성막 히터 엣지, 코터 EBR, CMP 리테이닝 링(타사) 어느 것도 될 수 있다.
- 확정은 맵이 아니라 **로트 이력과 공통성 분석**에서 난다: 어느 챔버를 거친 로트에만 나오는가(`--group-col`), 어느 시점부터인가(`--time-col`, `--event-col`), 로트 안에서 재현되는가(공정 조건) 한 장인가(이벤트).
- 테스트 자체가 원인일 수 있다(NEAR_FULL, 격자 주기 반복). 재테스트가 가장 싼 배제 수단이다.
- 평가 루프(R&D 팹)에서는 빈 맵보다 **파라메트릭 맵**(두께·CD)이 먼저 나오고, 그것이 장비 균일도를 직접 보여 준다. 빈 맵 판정은 양산 에스컬레이션 단계의 도구다([`tel_equipment_map.md`](tel_equipment_map.md) 4절).
- WM-811K에는 시각·챔버·슬롯·사이트·필드 정보가 없다. 그래서 이 저장소의 공통성·이벤트·슬롯 분석은 합성 데이터로 로직만 확인했고, 성능 주장이 아니다.
